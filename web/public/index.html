Your data

How Cadence uses Google Calendar

Connecting Google Calendar is optional. If you do, Cadence asks Google for permission to see and edit your calendar events, and uses it only for these features:

Show & import

Your Google events appear on Cadence's week and month calendars and sync to your other devices, updating when they change in Google.

Find open time

Your busy times are used to show the time you have free over the next 7 days on the Booking page.

Create & edit on request

Cadence adds, edits, or deletes a Google event only when you ask it to, for example a new event set to sync with Google.

We never sell your data or use it for ads, and you can disconnect at any time. Cadence's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Read the details in our Privacy Policy.

Download

Cadence on your computer

Desktop apps keep reminders running in the background and check in whenever you open your computer. Sign in with the same account and everything stays in sync.

Mac

Native app for macOS 14 or later. Apple Silicon and Intel.

Download for Mac First launch: if macOS can't verify it, open System Settings › Privacy & Security › Open Anyway.

Windows

Windows 10 and 11. Lives in the system tray and starts with Windows.

Download for Windows If SmartScreen appears, click More info › Run anyway.

Linux

AppImage for any distro, or a .deb for Debian and Ubuntu.

AppImage .deb
AppImage: run chmod +x Cadence.AppImage, then open it.

Or just use it in your browser: open the web app. All releases are on GitHub.
